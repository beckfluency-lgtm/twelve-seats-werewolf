# 隐私与权限

## 保存的数据

扩展使用 `chrome.storage.local` 保存座位平台、独立聊天网址、网页适配、游戏规则、身份、发言、行动和待回复请求。这些数据不会随项目源码分发。卸载扩展或清除浏览器数据可能删除存档，重要对局应自行导出备份。

“导出存档”包含完整游戏状态，可能包括私人身份、夜间选择、消息原文和带标识符的聊天网址。“导出适配配置”只包含平台控件配置，适合提交修复或分享给他人。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| storage | 在本机保存设置、待处理请求和对局 |
| tabs | 匹配已绑定聊天、打开玩家网址、保护工作标签页 |
| scripting | 在允许的平台网页填写、点击、读取正文及处理后台渲染 |
| 指定平台的网站访问权限 | 只允许操作清单列出的AI网站，不申请所有网站访问权限 |

扩展未申请 Cookie 读取、浏览历史、剪贴板、调试器或本机消息通信权限。项目代码不直接调用模型接口，不附带分析统计脚本，也没有项目自建后端。AI网站本身仍会发送其正常网络请求，并可能记录对话或访问行为。

游戏信息按公开和私人权限转发到所选平台。开局说明和夜间行动本身包含角色信息，使用者应确认这些平台适合接收该内容。不同AI聊天的服务端记忆与账号关联能力由平台控制。

## 提交问题

公开Issue中只提供平台名、版本号、错误文字和脱敏控件结构。截图应遮去账号、联系方式、聊天标识和与问题无关的内容。不要直接上传完整存档、浏览器配置文件或本地诊断导出。
