# 首次使用

## 加载扩展

将文件解压并保留在固定文件夹。浏览器加载的是这份文件夹，之后不要随意删除或移动。无需安装到某个盘符，也无需运行任何命令脚本。

Edge 在扩展管理页开启开发人员模式后，点击“加载解压缩的扩展”。如果选错层级，浏览器会提示找不到清单；重新选择直接包含 `manifest.json` 的文件夹即可。点击工具栏中的扩展图标打开观战台，不需要复制扩展编号。

## 准备12名玩家

在玩家配置中为各座位选择平台，并登录相应网站。多个座位可以共用同一平台账号，但必须各建一段独立聊天，不得复用同一个网址。聊天必须与下拉框中的平台匹配，不能填写登录页、首页或其他产品的入口。

先在网页手动发送一句简短问候，以确认账号能正常使用并生成聊天地址。复制地址栏中的完整网址到对应座位，修改自动保存。跨对话记忆、历史引用和个性化功能可能让同平台玩家互相影响，应在平台设置中关闭相关功能。程序只能隔离消息转发，不能控制平台内部的记忆机制。

AI种类不必恰好有12种。较少的平台配合独立聊天通常更方便维护。海外网站需要使用者自己的可用网络和账号；项目不提供代理或账号。

## 开始与继续

选择板子后点击“开始”。在12席全部确认规则和身份前，复盘区不会显示游戏开始。准备新局保留平台、网址和适配配置，重置游戏进度；新局会重新通知AI，不沿用旧局身份。

“暂停”会保留已发出的请求。之后点击“继续”读取原回复，不自动重发。暂停状态下的“结束”会结束本局。每次结束后建议导出存档，再准备新局。

## 异常处理

先看顶部状态栏中的席位与平台，点击“打开异常玩家对话”检查登录、额度、网络和实际回复。该按钮是你明确要求打开原网页的操作；正常轮询不会抢前台。

重新发送会创建新行动编号，旧回复不再作为当前行动接收。跳过只影响当前允许跳过的行动，投票视为弃票、技能视为不使用；规则、身份和必要进度确认不能跳过。等待期间也可以跳过。

更换AI时，填写新平台和新的独立聊天网址，再点击“更换AI”。更换在确认接入前不会覆盖原玩家；成功后程序通知原身份及允许接收的游戏进度。

若出现“发送按钮必须唯一”，不要连续点击重发。网站可能已经改版，在扩展选项中更新适配，或改用其他已支持的平台。星火当前使用 `#ask_window_send_btn`，箭头在填写文字后才出现。

## 更新与迁移

更新前先导出完整存档，保留一份旧扩展文件夹。将新版本文件放入原文件夹后，在扩展管理页重新加载。进行中的对局应先暂停，再重新打开观战台并继续。

换电脑或换浏览器时，重新安装扩展、登录AI平台、导入完整存档，并检查原聊天网址是否仍能访问。扩展编号可以变化，启动入口会自动使用当前编号。浏览器内部标签页编号不可跨电脑使用，导入时会清除并重新匹配。
