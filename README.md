# 十二席 AI 狼人杀观战台

让12名AI通过各自独立的聊天网页参与狼人杀，你在观战台旁观和复盘。程序在浏览器本地主持游戏，通过网页输入框、发送控件和回复正文收发信息，不调用模型API。

当前版本为 **0.2.0 测试版**。内置17个平台的控件配置，不需要复制开发者的浏览器设置，也不依赖固定安装目录、固定扩展编号或键盘辅助。网站改版、账号额度和登录状态仍会影响运行。

## 安装与开始

1. 下载发布包并解压到长期保留的文件夹。也可以下载仓库源码，解压后使用包含 `manifest.json` 的文件夹。
2. 在 Edge 打开 `edge://extensions`，开启开发人员模式，选择“加载解压缩的扩展”，选中上述文件夹。Chrome 的对应地址是 `chrome://extensions`。
3. 点击浏览器工具栏中的扩展图标，打开“十二席观战台”。可在扩展菜单中固定图标，之后从图标进入即可。
4. 在“玩家与独立对话”中选择平台，点击“打开平台网页登录”，登录你自己的AI账号。
5. 为每个座位建立独立聊天，填写完整聊天网址。同一平台可以安排多人，但12个座位必须使用12段不同的对话。若新对话仍显示首页地址，可先手动发送一句简短问候，取得独立聊天网址后再绑定。
6. 选择板子并点击“开始”。规则说明、身份通知和后续行动由程序自动发送。

使用者无需安装 Node.js、Python 或 PowerShell 脚本，无需API密钥。当前主要在 Windows 的 Edge 上验证。Chrome 及其他桌面系统仍需要更多实机反馈；Firefox、Safari 和手机浏览器不在支持范围内。

详细步骤见[首次使用](docs/QUICKSTART.md)，平台网址见[平台与适配](docs/PLATFORMS.md)。

## 游戏功能

- 标准预女猎白、狼王守卫、白狼王守卫三个12人板子，开局后锁定板子。
- 警长竞选、上警退水、警徽移交、1.5票权、遗言、狼人自爆与平票PK。
- 投票选择封存，全部收齐后统一公布，不将前序玩家的未公布选票传给后序玩家。
- 发言和行动分栏复盘，行动默认隐藏，仅上帝视角可查看私人行动。
- 随时更换AI，保留座位身份、技能与进度，自动说明规则并交接。
- 暂停继续、重新发送、跳过一次、本地存档与恢复。
- 保持原聊天，按席位补齐尚未确认的记录，减少重复上下文。

程序的具体房规以开局发送的全文为准。完整规则与版本随游戏存档保留。

## 运行与维护

正常收发不使用系统键盘、剪贴板或前台窗口焦点。浏览器和AI标签页需要保持打开；电脑睡眠、网页验证、额度耗尽和网络异常仍可能中断处理。异常时在顶部状态栏查看具体座位，可打开对应对话、重发或跳过允许跳过的行动。

星火输入框为空时可能只显示语音入口，输入文字后才出现发送箭头。清言的后台逐字显示已加入专门处理。不要仅凭是否看到发送按钮判断一条消息是否已经发出。

网站改版时，在浏览器扩展详情中打开“扩展选项”，可编辑平台适配并导入或导出配置。该设置页与观战台分开，不增加牌桌操作按钮。程序不会自动打开诊断窗口。适配配置不是API配置，只包含网页控件的CSS选择器与输入方式。

## 数据与权限

配置和对局保存在本机浏览器的扩展存储中。扩展不附带账号、Cookie、聊天网址或历史存档，也不设置项目服务器或遥测上报。游戏提示与记录会发送到你所选择的AI平台，平台自身的数据处理规则仍然适用。

导出的完整存档可能包含私人身份、夜间行动、网页地址和消息原文，请勿直接提交到公开仓库。若需要分享适配，在扩展选项中使用“导出适配配置”。详见[隐私与权限](docs/PRIVACY.md)。

## 开发

需要 Node.js 22 或更高版本，项目无第三方运行依赖，无需 `npm install`。

```sh
npm test
npm run check
npm run build
```

构建产物位于 `dist/`，包括可加载的扩展ZIP和SHA-256校验文件。源码仓库可直接作为解压缩扩展加载，不需要先构建。
